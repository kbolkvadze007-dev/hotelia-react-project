# სცენარი 3 — გაერთიანებული Hotel Booking App

ეს პროექტი აერთიანებს ორივე ZIP-ფაილის ფუნქციონალს ერთ React + Vite აპლიკაციაში.

## ფუნქციები
### სასტუმროს ნომრების კატალოგი
- ნომრების ბარათებით ჩვენება
- ნომრის სახელით ძებნა
- ნომრის ტიპით ფილტრაცია
- მაქსიმალური ფასით ფილტრაცია
- მხოლოდ თავისუფალი ნომრების ჩვენება
- ფასითა და სახელით დალაგება
- ფილტრების გასუფთავება
- რესპონსიული განლაგება

### ჯავშნების მართვა
- ჯავშნის დამატება Formik/Yup ვალიდაციით
- სტუმრის სახელის, ელფოსტის, რაოდენობისა და თარიღების ვალიდაცია
- ჯავშნების ძებნა და სტატუსით ფილტრაცია
- ჯავშნის დეტალების გვერდი
- ჯავშნის გაუქმება Redux Toolkit-ით

## გაშვება
1. გახსენით ეს საქაღალდე VS Code-ში.
2. ტერმინალში შეამოწმეთ, რომ იმყოფებით იმავე საქაღალდეში, სადაც `package.json` მდებარეობს.
3. გაუშვით:
   ```bash
   npm install
   npm run dev
   ```
4. გახსენით ტერმინალში ნაჩვენები `Local` მისამართი.

## Build-ის შემოწმება
```bash
npm run build
```

შენიშვნა: ნომრების კატალოგი იხსნება მთავარ მისამართზე `/`, ხოლო ჯავშნების მართვა — `/bookings`.
