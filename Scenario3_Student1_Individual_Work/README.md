# სცენარი 3 — ვერიკო ნაქევხრიშვილი
## ინდივიდუალური სამუშაო: Hotel Booking App — სასტუმროს ნომრების კატალოგი, ძებნა და ფილტრაცია

### ფუნქციონალი
- სასტუმროს ნომრების კატალოგის ჩვენება
- ნომრის სახელით ძებნა
- ნომრის ტიპით ფილტრაცია
- მაქსიმალური ფასით ფილტრაცია
- მხოლოდ თავისუფალი ნომრების ჩვენება
- რესპონსიული დიზაინი

### გაშვება
1. გახსენით ეს საქაღალდე Visual Studio Code-ში.
2. Terminal-ში გაუშვით `npm install`.
3. გაუშვით `npm run dev`.
4. გახსენით Vite-ის მიერ ნაჩვენები მისამართი.
